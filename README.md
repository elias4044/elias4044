## About Me

I'm a developer who builds because I genuinely can't *not* build. What started as curiosity—breaking things, fixing them, and going again—evolved into a genuine passion for full-stack development and creating products people actually use.

I'm obsessed with **systems that make sense**: clean architecture, smooth UX, thoughtful design. Not just things that work, but things that *feel right*. I work across the entire stack, from crafting responsive interfaces in React and Next.js to designing backend logic, APIs, and now—exploring the security layer underneath it all.

**Currently:** Leveling up through real projects, diving into automation and cybersecurity, learning how to ship ideas properly.

**Long-term Vision:** Build tools people can host themselves and truly own. The goal isn't just to code—it's to build things that matter.
